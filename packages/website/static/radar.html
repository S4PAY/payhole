Where this comes from
01
The swarm
Sinkhole nodes run by tier holders flag names. When enough separate operators agree, or one tier holder confirms a name already on a list as drainer infrastructure or a wallet drainer, every node blocks it. Those confirmations are what the radar counts.
02
The lists
Every node refreshes its subscribed lists and remembers what each refresh gained and lost. The brands come from the new names themselves: metamask-verify on a free hosting platform counts for MetaMask, metamask.io does not.
03
The same data, anywhere
This page reads dns.payhole.org/radar, JSON that any wallet, exchange, or dashboard may read too. The PayHole app for Android shows it on its Radar tab, and every Sinkhole node serves its own at /api/radar. Check one link if that is what you came for.
