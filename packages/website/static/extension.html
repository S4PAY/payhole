Get the extension
Extension

Load it unpacked. Chromium only, for now.

Until the store listing exists, the extension ships as a zip. It is Manifest V3 and runs in Chrome, Brave, Edge, and other Chromium browsers.

Download payhole-extension.zipWhat it can and cannot see
01

Unzip

Extract the zip into a folder you keep. The browser loads it from there on every start.

02

Load unpacked

Open chrome://extensions, turn on Developer mode, choose Load unpacked, pick the folder. Pin PayHole to the toolbar.

03

Create the vault

Open the popup, set a password, write down the seed phrase. The seed stays encrypted on your machine and never leaves the extension.

04

Fund the pocket

Send a little ETH for gas and some USDG to the owner address shown in the dashboard, create the BudgetAccount, set your caps. Done.

Try it

Naven runs a public x402 test endpoint on Robinhood Chain priced at 0.0001 USDG. Visit it with the extension unlocked and a funded pocket; the page loads and the ledger shows the payment.
