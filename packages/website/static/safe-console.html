PayHole Safe console

Runs the four owner calls on the BurnVault through the PayHole Safe, from one of the Safe's two owner wallets. Nothing here holds a key: your wallet signs each transaction, this page only builds it.

1. Connect an owner wallet

The Safe needs one signature from either of these two addresses. The page switches the wallet to Robinhood Chain, adding the network if it is missing.

Safe Owner A Owner B
not connected network unknown

2. Run the calls, in order

Each button sends one Safe transaction. Confirm it in your wallet, wait for the row to turn green, then press the next one. The first call can only ever run once, so it is disabled as soon as the vault has a token.
