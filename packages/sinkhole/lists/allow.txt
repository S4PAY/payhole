# PayHole Sinkhole allowlist.
#
# Names on this list are never blocked by a Sinkhole node, whatever a subscribed blocklist or a swarm
# verdict says. Public phishing lists are built from URLs, and when a phishing page sits on a shared
# platform the platform's own name ends up on the list: Google Sites, a video CDN, an IPFS gateway.
# Blocking such a name by DNS takes the whole platform down for the user while the phishing page
# lives at one path on it. This list takes those names back out.
#
# One rule per line. `example.com` protects that exact name only, so `evil.example.com` can still be
# blocked. `.example.com` protects the name and everything under it; use it only where no stranger can
# register a subdomain. `#` starts a comment.
#
# Every node fetches this file on the list refresh interval (ALLOWLIST_URLS). Run your own node with
# your own copy, or point MANUAL_ALLOWLIST_FILE at a local file to add rules. To report a name that
# should be here, open an issue at https://github.com/S4PAY/payhole.
